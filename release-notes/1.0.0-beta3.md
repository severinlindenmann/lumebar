## LumeBar 1.0.0-beta3

`1.0.0-beta3` focuses on shipping quality: packaging reliability and production-ready icon assets.

### Highlights
- Added script-based app packaging to produce `dist/LumeBar.app` and `dist/LumeBar.zip`.
- Added optional signing/notarization script for Developer ID distribution.
- Replaced icon set with a new app icon design and a cleaner monochrome menu bar glyph.
- Fixed menu bar icon sizing so it renders at a proper status-item scale.
- Fixed packaged app launch crash by bundling required SwiftPM dynamic libraries.
- Fixed app bundle icon metadata so the main app icon resolves correctly in Finder.

### Compatibility
- macOS 26+
- Swift 6.2
- Local Lume CLI installation required
- Local `lume serve` endpoint for list/details APIs
