## LumeBar 1.0.0-beta2

`1.0.0-beta2` focuses on stability and error handling improvements from beta feedback.

### Fixes
- Added explicit handling for missing `lume` binary so the app shows a clear install/PATH error instead of `no such file or directory`.
- Stabilized first-open layout while boot-time thumbnail data is pending.
- Switched thumbnail viewport to `4:3` using fit mode to prevent top/bottom cropping.

### Compatibility
- macOS 26+
- Swift 6.2
- Local Lume CLI installation required
- Local `lume serve` endpoint for list/details APIs
