## LumeBar 1.0.0-beta

`1.0.0-beta` is the first public beta release of LumeBar, a macOS menu bar app for managing Lume VMs.

### Highlights
- Menu bar VM management for list, start, stop, and screen sharing.
- Start/Stop operations use direct `lume` CLI execution.
- Start launches detached so VMs continue running after LumeBar exits.
- Snapshot thumbnails for running VMs on menu open.
- Details panel and menu sizing improvements.
- Refreshed app/menu bar icon set.

### Compatibility
- macOS 26+
- Swift 6.2
- Local Lume CLI installation required
- Local `lume serve` endpoint for list/details APIs

### Notes
- This is a beta release; behavior may change before stable `1.0`.
- If thumbnail frames appear black during very early guest boot, reopen the menu to refresh snapshots.
